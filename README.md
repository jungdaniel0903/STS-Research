# STS-Research
This Python script was utilized to train a Random Forest ML model on 65k+ National Bridge Inventory datapoints. Statistical analyses of the hypotheses and the efficacy of the model were evaluated in this script as well. 
# The Research Abstract is as follows:
Bridge deterioration models are built where inspection records are plentiful but needed where they are scarce. Using National Bridge Inventory data, this study examined what limits accuracy and how to judge whether a model can be trusted elsewhere. A Random Forest trained on 65,204 records from Texas, Louisiana, and Puerto Rico was evaluated under four definitions of deterioration with all else fixed. Predicting a one-point rating drop yielded an AUC of 0.78, whereas predicting entry into federal poor condition yielded 0.92 and held at 0.90 on unseen counties and 0.88 on future years. Adding noise matching federal findings that only 68% of inspector ratings agree within one point reduced it to 0.78, indicating that label noise, not model design, sets the accuracy ceiling. On 45 held-out bridges from Guam and the U.S. Virgin Islands, a high-risk model ranked high-risk bridges above chance (AUC 0.81, p = 0.002), though only nine were high-risk. Across 49 held-out states, the model’s calibrated confidence predicted transfer accuracy (ρ = 0.38, p = 0.007), while distance from the training data did not. Five climate tests found no transferable climate effect. A model’s reach depends more on outcome definition and label reliability than on its sophistication.
